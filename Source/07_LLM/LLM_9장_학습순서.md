# LLM 9장 복습과 실습 순서

수업을 놓쳤다면 모든 제공자와 벡터 데이터베이스를 동시에 익힐 필요는 없습니다. 먼저 **OpenAI 임베딩 → 로컬 Chroma → Pinecone** 한 줄을 끝까지 실행하세요. 그다음 Upstage와 Ollama 예제를 비교하면 됩니다.

## 먼저 알아둘 세 가지

1. **LLM**은 주어진 문맥으로 답을 생성합니다. 법률 문서를 자동으로 모두 알고 있는 것은 아닙니다.
2. **임베딩**은 문장과 질문을 숫자 벡터로 바꿉니다. 검색할 때 문서와 질문에 같은 임베딩 모델을 써야 합니다.
3. **RAG**는 문서 읽기 → 분할 → 임베딩 → 저장 → 유사도 검색 → 검색된 문맥과 질문을 LLM에 전달하는 흐름입니다. Pinecone은 이 중 벡터 저장·검색을 담당합니다.

## 내 자료에서 확인한 상태

- `ch09.01`의 임베딩 비교, `ch09.02~04`의 모델 호출, `ch09.05`와 `ch09.06`의 RAG·Chroma 실습은 노트북에 대부분 실행 흔적이 있습니다. 실행 기록은 현재 내 계정에서 다시 성공한다는 뜻은 아닙니다.
- `ch09.07` Upstage+Chroma는 대부분 실행되지 않았고, `ch09.08`의 두 버전은 실행 상태가 서로 다릅니다.
- `ch09.09` OpenAI 임베딩+Pinecone에는 `NameError` 두 개가 남아 있습니다. 앞에서 검색 결과와 모델을 만드는 셀을 건너뛰면 뒤의 프롬프트 셀이 실패합니다.
- Pinecone 계정에는 처음에 인덱스가 없었습니다. `tax-index-openai`를 3072차원·cosine으로 만들고 소득세법 조각 180개를 저장했습니다. 콘솔에서 기록 수 180을 확인했습니다.
- 복습 노트북에서 문서 분할, 3072차원 임베딩, Pinecone 검색, LLM 답변까지 실행했습니다. 실행 중 빠진 `pinecone`, `langchain-pinecone` 패키지도 수업 커널에 설치했습니다.
- 수업 폴더 `.env`에는 `OPENAI_API_KEY`, `UPSTAGE_API_KEY` 항목이 있고 `PINECONE_API_KEY` 항목은 없습니다. 실습용 Pinecone 키는 현재 Jupyter 커널 메모리에만 연결했고 파일에는 저장하지 않았습니다. 새 커널에서는 키를 다시 입력해야 합니다.

## 따라 할 순서

1. **기초 이해**: `ch09.01_vectorEmbeddingModel성능비교.ipynb`의 코사인 유사도와 임베딩 출력 길이를 봅니다. `text-embedding-3-large`의 기본 길이는 3072입니다.
2. **모델 호출**: `ch09.02_ChatOpenAI와 렝체인을 활용한 검증.ipynb`에서 SDK 호출과 LangChain 호출이 같은 질문을 처리하는 두 방법임을 확인합니다. Upstage/Ollama는 뒤에 비교합니다.
3. **RAG 원리**: `ch09.05_vectorStore저장없이 RAG구현.ipynb`에서 문서를 조각내고, 질문과 비슷한 조각을 찾아 답변에 넣는 순서를 봅니다.
4. **로컬 저장**: `ch09.06_LangChain과 vectorDatabase(파일)를 활용한 RAG구현.ipynb`에서 Chroma가 벡터를 컴퓨터에 저장한다는 점을 확인합니다.
5. **Pinecone 계정 연결**: Pinecone 콘솔의 `tax-index-openai` 인덱스가 3072차원·cosine인지 확인합니다. Pinecone API 키는 노트북의 숨김 입력창에 넣습니다. 채팅이나 노트북 코드에 키를 적지 않습니다.
6. **새 복습 노트북 실행**: `ch09_복습_Pinecone_따라하기.ipynb`를 위에서 아래로 실행합니다. 문서 읽기, 분할, OpenAI 임베딩, Pinecone 저장, 검색, LLM 답변을 한 경로로 연결했습니다.
7. **검증**: Pinecone 콘솔의 기록 수가 0에서 늘었는지 보고, 검색한 세 조각이 질문과 관련 있는지 살핍니다. 답변은 검색된 원문과 대조합니다.
8. **심화 비교**: 한 경로가 끝난 뒤 `ch09.07`과 `ch09.08`에서 Upstage 임베딩 버전을 봅니다. 다른 임베딩 모델은 차원이 다를 수 있으므로 기존 OpenAI 인덱스에 섞어 넣지 않습니다.

## 자주 막히는 지점

- `NameError`: 커널을 다시 시작하고 셀을 위에서부터 실행합니다.
- `401/403`: Pinecone/OpenAI 키와 프로젝트 권한을 확인합니다. 키를 화면 공유나 채팅에 붙이지 않습니다.
- `Index not found`: Pinecone에서 현재 선택된 프로젝트와 노트북의 인덱스 이름이 같은지 확인합니다.
- `dimension mismatch`: Pinecone 인덱스 3072와 OpenAI 임베딩 출력 3072가 같은지 확인합니다.
- 검색 결과 0개: 인덱스의 기록 수와 첫 저장 셀의 실행 결과를 확인합니다.

소득세법 예제는 RAG 학습용입니다. 연봉만으로 개인의 실제 세액을 확정할 수 없으므로, 예제 답변을 신고나 납부 판단에 사용하지 마세요.
